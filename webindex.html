Learning Modules — 01 through 07

The Journey

Every day introduced a new concept. Click any card to view the assignment for that day.

DAY 01
Basic HTML Tags

Learned the core building blocks of the web — headings, paragraphs, ordered & unordered lists, and div tags. Understood how even tiny tag changes affect how browsers render content.

View Assignment 01
DAY 02
Images, Anchors, Video & Tables

Added images, video, audio and links to make pages look good and clean. Learned how users move between pages and how two HTML files can link using the <a> tag.

View Assignment 02
DAY 03
Forms & User Input

Learned how forms are built using the <form> tag, how to capture input using <input>, how type sets what data is accepted, and how placeholder guides the user.

View Assignment 03
DAY 04
Header, Nav, Footer & Basic CSS

Built structured web pages using semantic HTML elements — header, nav, main content, and footer. Applied basic CSS to style layouts with colors, spacing, and interactive navigation.

View Assignment 04
DAY 05
Box Model & Flexbox

Mastered the CSS Box Model — margin, padding, border, and content — to control layout spacing. Used Flexbox to create responsive, flexible layouts that align and distribute elements efficiently.

View Assignment 05
DAY 06
JavaScript Basics

Learned JavaScript fundamentals — variables, data types, functions, and basic DOM manipulation. Used JavaScript to add interactivity and dynamic behavior to web pages for the first time.

View Assignment 06
DAY 07
Final Project — To-Do List

Built a complete To-Do List app — add, delete, and mark tasks as completed. An interactive interface combining everything learned across all 7 days of HTML, CSS, and JavaScript.
